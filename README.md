# ProfessorAte

## About
The goal of this project is to offer to portuguese students a platform to securely and safely rate professors you have attended classes for so that other student can see how they their methods are generally seen by their pears.

### Features
This platform will allow user to rate professors on a series of categories in a given scale.  **No written personalized rating is allowed** for security reazons.  **No photos of professors or students is allowed to be shared** for privacy protection reazons.
You can than search a professor either by name, school or classes and see how your colleges have been rating them over the years or their current tendency.
